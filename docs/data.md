# Data and pipeline

How the data is collected, what each file holds, and the caveats that matter for point-in-time use. The scripts are in `pipeline/`; run them from the repository root.

## Requirements and setup

- MATLAB R2019b or later, no extra toolboxes (`webread`, `readcell`). `pipeline/fetch_fomc_minutes.m` needs R2022a or later; it uses the Text Analytics Toolbox if installed, else plain MATLAB.
- A free [FRED API key](https://fred.stlouisfed.org/docs/api/api_key.html), set with `setenv("FRED_API_KEY", "your_key_here")`. That lasts for the MATLAB session; to set it at every launch, put the line in a `startup.m` outside the repo so the key stays out of version control.
- An internet connection.
- `data/fomc_meeting_dates.csv`, written by `pipeline/fetch_fomc_minutes.m`: `Date` (last day of each meeting, `yyyy-mm-dd`) and `ReleaseDate` (when the minutes were published), one row per scheduled meeting since 2008. Unscheduled meetings and conference calls are not included. Only step 5 of `pipeline/macroeconomic_data.m` needs it.

## Running the pipeline

Each script is split into sections: run one at a time (Ctrl+Enter), in this order. Keep MATLAB's current folder at the repository root; the scripts read and write `data/` relative to it.

| Step | Script / section | What it does | Writes (in `data/`) |
|------|------------------|--------------|---------------------|
| 1 | `pipeline/macroeconomic_data.m`, section 1 | Defines the series catalog (46 FRED series, flagged revised or not) | none |
| 2 | section 2 | Pulls current-vintage values for every FRED series | `fred_current.mat` |
| 3 | section 3 | Pulls the full vintage history (ALFRED) for the 17 revised series | `fred_vintages.mat` |
| 4 | section 4 | Pulls total public debt and the average interest rate on marketable Treasury debt from the Treasury FiscalData API (no key) | `debt_to_the_penny.csv`, `avg_interest_rates.csv` |
| 5 | `pipeline/market_data_extra.m` | Pulls S&P 500 daily closes and Shiller monthly data | `gspc_daily.csv`, `shiller_monthly.csv` |
| 6 | `pipeline/export_csvs.m` | Combines everything into the output CSVs | see Output files |
| 7 (optional) | `pipeline/macroeconomic_data.m`, section 5 | Builds the meeting-aligned dataset | `fomc_aligned_macro.csv`, `fomc_aligned_macro.mat` |

`export_csvs.m` needs the outputs of steps 2 to 5 and stops with an error if any are missing. Step 7 is not needed for the export.

**Notes on the pulls**

- **FRED** requests are paced (0.6 s apart) to stay under the rate limit. Failures are reported as warnings with the API key masked.
- **S&P 500** comes from Yahoo's unofficial chart API. If it fails, save the `^GSPC` history from finance.yahoo.com as `data/raw/GSPC_yahoo_manual.csv` (columns `Date` and `Close`).
- **Shiller** has no API: the script finds the current `ie_data.xls` link on [shillerdata.com](https://shillerdata.com/) and downloads it to `data/raw/`. If that fails, save it by hand as `data/raw/ie_data.xls`; if MATLAB cannot read `.xls`, convert it to `data/raw/ie_data.xlsx`.
- **Frozen files.** `market_data_extra.m` reuses `gspc_daily.csv` and `shiller_monthly.csv` if they exist; set `refresh = true` at the top to pull again.
- **Treasury.** If the API fails, check the field names against the [FiscalData docs](https://fiscaldata.treasury.gov/api-documentation/). The same API has auction and issuance data (`auctions_query`) that could be added with the same paging pattern.

## Output files

| File | Description | Shape |
|------|-------------|-------|
| `macro_market_wide.csv` | One row per date, one column per series; blank where a series has no value | 13,431 rows x 53 columns |
| `fred_vintages_long.csv` | Revision history of the revised FRED series: `date, series_id, value, rtStart, rtEnd` | 47,424 rows x 5 columns |
| `series_dictionary.csv` | One row per series: label, source, frequency, first and last date, observation count, units, notes | 52 rows x 13 columns |
| `raw_series_long.csv` | Every series stacked: `date, series_id, value, source, frequency`. Generated by `export_csvs.m`, not committed (6.2 MB) | 168,204 rows x 5 columns |
| `fomc_aligned_macro.csv` | One row per FOMC meeting with the latest known value of each series (optional) | |

`series_dictionary.csv` columns: `series_id`, `label`, `source`, `frequency`, `first_date`, `last_date`, `n_obs`, `revised`, `units`, `fred_title`, `seasonal_adjustment`, `pull_date`, `notes`. Units, FRED title and seasonal adjustment are filled in only when `FRED_API_KEY` is set.

**Meeting-aligned dataset.** For each meeting in `fomc_meeting_dates.csv`, the information set is everything known the day before:

- *Revised series* (17): the vintage current that day, from the real-time window (`rtStart`, `rtEnd`). A `<series>_lagDays` column gives the age of the latest reading in days.
- *Unrevised series*: the last observation on or before that day.

Sources: **FRED**, **Yahoo Finance** (`^GSPC`), **Shiller** (shillerdata.com) and **US Treasury FiscalData** (Debt to the Penny, Average Interest Rates on U.S. Treasury Securities). Shiller's CPI and GS10 are left out of the export: FRED has both, and Shiller carries them forward past the latest release.

## Design notes

- **No forward filling.** Missing values are dropped from the long file and blank in the wide file, so no value appears before it was dated.
- **Future-dated rows are removed**, such as CBO projections to 2036 for `GDPPOT` and `NROU`. The full projection history stays in the vintage file.
- **Revisions are kept.** `fred_vintages_long.csv` stores each value with the window in which it was current (vintages from 1990-01-01).
- **Frequency is inferred** from the median gap between observations.
- **Validation.** `export_csvs.m` checks for duplicate `(date, series_id)` rows and series with no data, then prints a summary of every series.

## Caveats

Also recorded in the `notes` column of `series_dictionary.csv`.

- **Publication lags.** `FEDFUNDS`, `UMCSENT`, `MICH`, `GACDFSA066MSFRBPHI`, `GACDISA066MSFRBNY` and `ICSA` are dated at the start of the period but published later: lag them before aligning to meetings (the agent uses `series_availability.csv`).
- **Shiller.** `SHILLER_PRICE` and `SHILLER_CAPE` use monthly average prices, so a month is not known until it ends and the latest row is partial. After the last month with earnings, Shiller estimates earnings and CPI. `SHILLER_DIVIDEND` and `SHILLER_EARNINGS` are published months late, so the latest rows are missing.
- **`GSPC`** is a price index without dividends; the last bar excludes the current day.
- **`SP500`** (FRED) covers only about 10 years: use `GSPC` for the long history.
- **`BAMLH0A0HYM2`** (FRED) is truncated to about 3 years: use `BAA10Y` as the credit spread.
- **`THREEFYTP10`** is a Kim-Wright model estimate that can be revised, and it runs about a week behind.
- **`GDPPOT`, `NROU`** are CBO estimates.
- **`DFEDTAR`** is the single fed funds target and ends in December 2008; `DFEDTARU` and `DFEDTARL` cover the range afterwards.
- **Unofficial sources.** Yahoo's API is unofficial and the Shiller download reads the shillerdata.com page, so either can break; the manual fallbacks above cover both.

## FOMC minutes

`pipeline/fetch_fomc_minutes.m` downloads the minutes of every scheduled meeting from 2008 on from [federalreserve.gov](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm): the calendar page for recent years, the yearly historical pages for earlier ones. It currently covers 150 meetings, January 2008 to September 2026. Run it from the repository root (3 to 5 minutes, one request per second); re-running picks up newly released minutes.

It reads each meeting's date, release date and HTML and PDF links from the calendar pages; extracts the text from the HTML (Text Analytics Toolbox `htmlTree`/`extractHTMLText`, or a plain-MATLAB fallback), removing navigation, footer and footnote numbers and decoding older Windows-1252 pages; splits each document into its standard sections by heading; and writes the files below. The PDFs are an archive only; the text comes from the HTML.

| File | Contents |
|------|----------|
| `data/minutes/fomc_minutes.mat` | Table `fomcMinutes`, one row per meeting, all columns below |
| `data/minutes/fomc_minutes.csv` | Same without `Text` (dates as `yyyy-mm-dd`, text fields quoted) |
| `data/minutes/txt/fomcminutes<MeetingDate>.txt` | Full cleaned minutes for one meeting (identical to `Text`) |
| `data/minutes/pdf/` | Official PDFs; ignored by git, re-downloaded if missing |
| `data/fomc_meeting_dates.csv` | `Date` and `ReleaseDate` for each meeting |

| Column | Contents |
|--------|----------|
| `MeetingDate` | Last day of the meeting; files are named by it |
| `ReleaseDate` | When the minutes were published, usually 3 weeks later |
| `URL` | Source page on federalreserve.gov |
| `Text` | Full minutes with headings, attendance and footnotes (`.mat` only) |
| `Body` | The seven substantive sections below, joined; use this for text analysis |
| `FinancialMarkets` | Developments in Financial Markets and Open Market Operations |
| `StaffEconomy` | Staff Review of the Economic Situation |
| `StaffFinancial` | Staff Review of the Financial Situation |
| `StaffOutlook` | Staff Economic Outlook |
| `ParticipantsViews` | Participants' Views on Current Conditions and the Economic Outlook |
| `PolicyAction` | Committee Policy Action(s): the decision, statement and vote |
| `SpecialTopics` | One-off discussions (balance sheet, framework review, repo facility, ...); empty at many meetings |
| `Administrative` | Organizational matters, officer elections, rule changes, notation votes |
| `Attendance` | Meeting header, attendance list and signature |
| `Footnotes` | Footnote text |

**Line up the minutes with market data on `ReleaseDate`, not `MeetingDate`.** The minutes are public only from 2:00 p.m. ET on the release date; using the meeting date gives the text a three-week head start it never had (look-ahead bias).

Older minutes:

- **2008** has no section headings, so sections are split on each one's standard opening sentence (e.g. "The information reviewed at the March meeting...").
- **2008 to mid-2009:** the staff's economic and financial reviews were one section. The combined text is in `StaffEconomy`; `StaffFinancial` is empty for 10 meetings.
- **2008:** text before the first section (attendance, and in January the organizational matters) is in `Attendance`, as are the footnotes of four meetings (January, April and June 2008, August 2010). None of it is in `Body`.
